## 3. 一致性检查

- [ ] 对照 `src/` 验证所有模块、类、流程和依赖名称。

- [ ] 对照测试验证状态转换、失败分支、恢复、事务和外部服务边界。
- [ ] 搜索文档中的“当前、已经、支持”等断言，确认均有证据。
- [ ] 确认 To-Be 章节和图没有被描述成当前实现。
- [ ] 确认没有虚构案例、通用百科章节或大段复制代码。

## 4. 文档验证

- [ ] 检查 HTML 标题层级、目录锚点、表格语义和页面结构。

- [ ] 对本次任务运行 Trellis 全范围检查，按审查结果修正文档。

## 5. 风险与回滚点

- 最大风险是文档事实错误或把未来设计写成当前行为；每章完成后立即对照源文件，避免最后集中返工。
- SVG 长图需要在窄屏保持完整可缩放；复杂视角优先纵向布局并允许图片容器横向查看。
- 根 `README.md` 当前为空；只写最小项目入口，避免在 README 重复架构正文。
- 如无法验证某项结论，将其标注为推断/待确认或删除。
- 本任务不修改运行时代码；回滚点是删除 HTML 与 SVG 资源并恢复 README 入口。
