# 建立 Meta 字段语义与取值索引

## Goal

让 Data Agent 能按自然语言检索 Meta 中的表、字段和指标语义，并能把用户提到的业务值定位到正确字段，为后续问数选表、选字段和条件生成提供可靠候选。

Meta MySQL 继续作为元数据真相源；检索索引是可重建投影，不反向替代或污染 Meta 数据。

## Background

- Meta 当前使用 `table_info`、`column_info`、`metric_info`、`column_metric` 保存表、字段、指标及其关联。
- `column_info` 已包含 `role`、`description`、`alias`、`examples`，无需为字段语义重复建模。
- 当前快照写入把 `column_info.examples` 固定为 `[]`，仓库内没有字段值采样或更新链路。
- 当前 Qdrant / Elasticsearch 索引只服务长期记忆，不能与元数据索引混用。
- 元数据索引必须允许从 Meta 与业务数据重新构建；索引失败不得回滚已经成功提交的 Meta 快照。

## Requirements

- R1：为表、字段和指标建立独立的元数据语义索引，支持名称、别名、描述及上下文的混合检索。
- R2：为符合条件的业务字段建立独立的字段值索引，支持精确、模糊和按候选字段过滤的检索。
- R3：LLM 必须结合整张表的角色、描述、字段类型、字段注释和字段关系，同时判断字段值是否具有问数检索价值及是否敏感。字段名规则只能作为风险证据，不能单独决定分类；真实字段值不发送给 LLM。LLM 输出 `index / skip / unknown` 三态值索引决策、`non_sensitive / sensitive / unknown` 三态敏感度及可对应到真实表、字段、注释和关系的证据；仅 `index + non_sensitive + 证据完整且无冲突` 的字段获得值索引资格。不得使用未经校准的数值置信度，也不得用当前数据是否已同步、当前基数或当前数据量决定资格；每字段运行时最多有界保留高频 10,000 个值。
- R4：检索采用两阶段流程：先定位候选表/字段/指标，再在候选字段范围内检索业务值。
- R5：所有索引文档使用稳定 ID 和源数据版本标识，重复同步必须幂等。
- R6：Qdrant 元数据语义 collection 与 Elasticsearch 字段值 index 必须在处理业务数据前幂等创建并严格校验 mapping；Meta 快照提交后异步写入表、字段、指标语义文档和字段资格。
- R7：索引失败不得改变 Meta 或 DW 同步成功状态；索引更新使用独立的持久化重试并支持手动全量重建，系统接受 Meta、DW 与索引之间的短暂最终一致性延迟。
- R8：元数据索引与现有长期记忆 collection / index 完全隔离；本任务只提供内部索引与检索模块及其集成验证，不新增公共接口或用户问答入口。
- R9：DW 尚无数据时，字段值索引结构和字段索引资格仍须提前建立，字段保持等待值填充状态；数据增长后继续按同一上限动态维护，不得把空表判定为无索引价值。
- R10：字段值可在 DW `backfilling / replaying` 期间随数据到达增量写入；只有对应表进入 `streaming` 且不存在待处理刷新时，检索结果才能标记为完整可用，未就绪期间的部分索引不得作为完整值域使用。

## Acceptance Criteria

- [ ] 输入字段名称、别名或业务描述，能够返回相关字段及其所属表，并给出可解释的命中信息。
- [ ] 输入指标名称、别名或业务问题，能够返回相关指标和关联字段。
- [ ] 输入业务值并限定候选字段后，能够返回匹配值、字段和所属表。
- [ ] 不符合索引策略的字段不会采集或写入字段值索引。
- [ ] LLM 决策为 `unknown`、敏感度为 `unknown`、证据缺失或证据冲突的字段只建立语义索引，不写入字段值索引。
- [ ] 在 DW 无数据时，Qdrant / Elasticsearch 索引结构已经存在，Meta 语义文档和高价值字段资格可正常写入。
- [ ] DW 数据在回填或追赶期间到达后，字段值可增量写入；进入 `streaming` 后标记为完整可用。
- [ ] 同一份 Meta 快照和业务值重复同步不会产生重复文档。
- [ ] 模拟索引写入失败时，Meta 已提交状态保持成功，后续重试可恢复索引。
- [ ] 可从 Meta 与业务数据执行全量重建，并与增量同步结果一致。

## Out of Scope

- 本任务不改变 Meta 四张核心表的业务边界。
- 本任务不把长期记忆与元数据合并为同一检索索引。
- 本任务不新增对外 HTTP 接口，也不实现最终用户问答或 SQL 生成完整链路。
