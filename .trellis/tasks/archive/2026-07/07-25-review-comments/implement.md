## 回滚点

- 正式审查前：可重建任务目录中的清单和研究文件，不触碰产品文件。
- 报告聚合后：若独立复核发现误报，只修订任务报告及研究产物。
- 注释实施后：使用 Git diff 定点撤销本任务的注释改动；不得使用 reset、checkout 或清理用户工作区。
- 任何 Git 操作前：重新核对工作区，只处理本任务目录。
